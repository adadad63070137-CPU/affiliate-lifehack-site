== 第1章 エーゲ文明 ==
0:00  ギリシア神話には、牛の頭をもつ怪物ミノタウロスが閉じこめられた「迷宮」が出てきます。
0:06  その舞台とされるクレタ島で、実際に巨大な宮殿のあとが見つかりました。
0:11  この宮殿の文明から、アテネとスパルタ、アレクサンドロス大王、そしてローマの誕生まで。
0:17  地中海の1700年を、地図でひとつながりにたどります。
0:22  紀元前2000年ごろ、このクレタ島で栄えたのがクレタ文明です。
0:26  中心のクノッソス宮殿は、何百もの部屋が入り組んだつくり。これが迷宮伝説のもとになったと考えられています。
0:34  宮殿には城壁がなく、壁画にはイルカや人々が明るく描かれています。
0:39  海の交易で栄えた、平和で開放的な文明でした。
0:43  彼らが使った文字は線文字A。この文字は、今もまだ解読されていません。
0:49  そのころ、北のバルカン半島から、ギリシア人が南へ移ってきます。
0:53  彼らが紀元前1600年ごろから築いたのがミケーネ文明です。
0:58  クレタとは対照的に、巨大な石を積んだ城塞をもつ、戦士たちの文明でした。
1:04  彼らの文字は線文字B。こちらは20世紀に、イギリスのヴェントリスが解読に成功しています。
1:11  ホメロスの叙事詩で歌われたトロイア戦争も、この時代が舞台とされています。
1:16  この物語を信じて、トロイアとミケーネを実際に掘りあてたのが、ドイツのシュリーマンでした。
1:22  しかし紀元前1200年ごろ、ミケーネ文明は突然ほろびます。
1:27  そのあとギリシアは、約400年にわたって文字の記録がとだえる暗黒時代に入りました。
1:34  ただ、このあいだに鉄器が広まり、次の時代への準備が進んでいきます。

== 第2章 ポリスの誕生 ==
1:40  紀元前8世紀、暗黒時代が終わると、人々は有力な貴族のもとに集まって住むようになります。
1:46  これを集住、シノイキスモスといいます。
1:49  こうして生まれた都市国家がポリスです。
1:52  ポリスの中心には、神殿が建つ守りの丘アクロポリスと、市場や話し合いの場になる広場アゴラがありました。
2:00  ポリスは200以上もあり、最後までひとつの国にまとまることはありませんでした。
2:05  それでも、同じ言葉を話し、同じ神々を信じる仲間として、自分たちをヘレネスと呼びました。
2:12  それ以外の人々はバルバロイ、「わけのわからない言葉を話す者」と呼んで区別します。
2:18  デルフォイのアポロン神殿の神託や、4年に一度のオリンピアの祭典も、仲間意識を強めました。
2:26  人口がふえると、ギリシア人は地中海や黒海の沿岸に、次々と植民市を築いていきます。
2:33  今のマルセイユ、ナポリ、イスタンブールも、もとはギリシア人の植民市でした。

== 第3章 アテネとスパルタ ==
2:40  たくさんのポリスの中でも、とくに有力だったのが、アテネとスパルタです。
2:45  スパルタは、南下してきたドーリア人が、先住民を征服してつくったポリスです。
2:50  少数の市民が、商工業をになうペリオイコイと、農業をさせられた大勢の奴隷身分ヘイロータイを支配していました。
2:59  反乱をおさえるため、男の子は7歳から集団生活できたえられ、国全体が軍隊のようになります。
3:06  一方、イオニア人のポリス、アテネは、商工業や海の交易で栄えました。
3:12  はじめは貴族が政治をにぎっていましたが、豊かになった平民が、武器を自分でそろえるようになります。
3:19  こうして平民が重装歩兵として、国を守る主力になりました。
3:24  国を守る平民たちは、政治に参加する権利も求めはじめます。
3:28  紀元前594年、ソロンは、借金で市民が奴隷になることを禁止し、財産に応じて政治に参加できるようにしました。
3:37  その後、平民の支持で権力をにぎったペイシストラトスの僭主政をへて、
3:43  紀元前508年、クレイステネスが民主政の土台をつくります。
3:47  独裁者になりそうな人物を、陶器のかけらに名前を書いて追放する陶片追放も、このとき始まりました。

== 第4章 ペルシア戦争 ==
3:55  そのころ東では、アケメネス朝ペルシアが、エジプトからインダス川までを支配する大帝国を築いていました。
4:03  紀元前500年、ペルシアに支配されていたイオニア地方のギリシア人が反乱を起こし、アテネがこれを助けます。
4:10  これがきっかけで、ペルシア戦争が始まりました。
4:13  紀元前490年、ペルシア軍はアテネの近くのマラトンに上陸。アテネの重装歩兵がこれを打ち破ります。
4:22  勝利を伝えるために兵士が走り続けたという話が、マラソン競技の由来です。
4:28  10年後の紀元前480年、ペルシアは大軍で再び攻めこみます。
4:33  テルモピレーでは、スパルタ王レオニダスが少数の兵で立ちはだかりますが、全滅してしまいます。
4:40  しかし同じ年、テミストクレスが率いるアテネ海軍が、サラミスの海戦でペルシア艦隊に大勝利します。
4:48  主力は三段櫂船。この船をこいだのは、武器を買えない貧しい市民、無産市民でした。
4:55  彼らの活躍が、のちに民主政をさらに広げることになります。
4:59  翌年、プラタイアの戦いにも勝ち、ギリシアはペルシアを退けました。

== 第5章 民主政の完成とペロポネソス戦争 ==
5:05  戦いのあと、アテネはペルシアの再来にそなえてデロス同盟をつくり、その盟主になりました。
5:12  将軍ペリクレスの時代、アテネの民主政は完成します。
5:17  成年男性市民が全員参加する民会で物事を決める、直接民主政です。役人の多くは、くじ引きで選ばれました。
5:25  ただし、女性や奴隷、在留外人には、参政権がありませんでした。
5:32  アクロポリスには、今も残るパルテノン神殿が建てられます。
5:36  実はその費用の一部には、デロス同盟の資金が使われていました。
5:41  力を強めるアテネを、スパルタは警戒します。
5:44  紀元前431年、アテネ中心のデロス同盟と、スパルタ中心のペロポネソス同盟のあいだで、
5:52  ギリシアを二分するペロポネソス戦争が始まりました。
5:55  アテネでは疫病がはやり、ペリクレスも亡くなってしまいます。
5:59  その後は、人気取りの政治家デマゴーゴスが民衆をあおる、衆愚政治におちいりました。
6:06  さらにペルシアがスパルタに資金を出し、紀元前404年、アテネは降伏します。
6:13  その後も、スパルタ、テーベと主導権が移りかわり、争いに疲れたポリスは、力を失っていきました。

== 第6章 アレクサンドロス大王とヘレニズム ==
6:20  そのギリシアの北で力をつけたのが、マケドニア王国です。
6:24  紀元前338年、国王フィリッポス2世はカイロネイアの戦いでアテネとテーベの連合軍を破り、ギリシアを支配下におきました。
6:34  父のあとをついだアレクサンドロスは、紀元前334年、ペルシアを目指して東方遠征に出発します。
6:41  イッソスの戦いでペルシア王ダレイオス3世を破り、エジプトでは、自分の名前をつけた都市アレクサンドリアを建てました。
6:50  そして紀元前330年、ついにアケメネス朝をほろぼします。
6:55  遠征はインダス川にまで達しましたが、紀元前323年、大王はバビロンで病死。まだ32歳の若さでした。
7:04  大王の死後、帝国は部下の将軍たちに分けられ、3つの王朝が並び立ちます。
7:10  マケドニアのアンティゴノス朝、シリアのセレウコス朝、エジプトのプトレマイオス朝です。
7:17  こうしてギリシアの文化はオリエントまで広がり、東西の文化がまじりあったヘレニズム文化が生まれます。
7:24  エジプトのアレクサンドリアにはムセイオンという研究所がつくられ、学問の中心になりました。
7:30  人々はポリスのわくにとらわれず、自分は世界の市民だと考える世界市民主義も広がりました。

== 第7章 ローマの誕生と共和政 ==
7:37  ギリシアの西、イタリア半島では、もうひとつの物語が進んでいました。
7:42  伝説では紀元前753年、狼に育てられた双子の兄ロムルスが建てたとされる都市、それがローマです。
7:50  ローマは、ラテン人の小さな都市国家として始まりました。
7:55  はじめ、ローマは北に住むエトルリア人の王に支配されていましたが、
8:00  紀元前509年、王を追い出し、共和政をはじめます。
8:04  国のトップは、任期1年で2人のコンスル。
8:08  政治の実権は、貴族パトリキが独占する元老院がにぎっていました。
8:13  でも、ここでもアテネと同じことが起こります。重装歩兵として戦う平民プレブスが、権利を求めはじめたのです。
8:22  まず、平民を守る護民官と、平民だけの集会平民会がつくられます。
8:28  紀元前450年ごろ、ローマ最初の成文法十二表法が定められ、
8:33  紀元前367年のリキニウス・セクスティウス法で、コンスルの1人を平民から選ぶことになりました。
8:41  そして紀元前287年のホルテンシウス法で、平民会の決議が、元老院の承認なしで国の法律になります。
8:50  この長い争いを身分闘争といいます。
8:54  国内をまとめたローマは、紀元前272年、南イタリアのギリシア人植民市タレントゥムを攻め落とし、
9:02  イタリア半島の統一をなしとげました。
9:04  征服した都市には、それぞれちがう権利を与えて団結させない、分割統治で支配しました。

== 第8章 総まとめ ==
9:11  最後に、流れをふりかえりましょう。
9:14  エーゲ海の宮殿の文明のあと、ギリシアではポリスが生まれ、アテネは戦いの中で民主政を育てました。
9:21  しかしポリスどうしの争いで力を失い、アレクサンドロスがギリシアとオリエントをひとつにします。
9:28  同じころ西では、ローマが平民と貴族の対立を乗りこえ、イタリア半島を統一しました。
9:35  戦いで国を守った市民が、政治への参加を勝ちとっていく。これはアテネとローマに共通する流れです。
9:41  このあとローマは地中海へ乗り出し、ギリシアから受けついだ文化とともに、大帝国へと成長していきます。
