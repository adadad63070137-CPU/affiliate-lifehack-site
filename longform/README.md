# 世界史ずかん 長編（YouTube 横型動画の自動生成）

ショート（`shorts/`）と同じ仕組み（VOICEVOX＋Natural Earth の地図＋Pillow 描画＋ffmpeg）を、
**横型 1920×1080 / 30fps・5〜10分**の長編向けに作り直したものです。

## 長編の構成ルール

ショートのアナリティクス（冒頭で75〜78%が離脱）をふまえて、長編でも次のようにしています。

1. **0秒目から内容を見せる**：1コマ目から地図・迷宮の図・問いかけ（「迷宮は実在した？」）が全部見えている（フェードインしない）
2. **前置きは1文だけ**：あいさつやチャンネル紹介は入れず、つかみの2文のあと「どこまで進むか」を1文で示して本題へ
3. **物語形式で通す**：章の区切りは左上に数秒出る控えめな見出しと、ヘッダーの章名だけ。受験用語は字幕の赤字で押さえる
4. **次回予告で終わらない**：最後は総まとめの年表図を残して終わる（終了画面の要素を置く余白にもなる）

## 実写寄りの見た目（#2〜、`Video(look="doc")`）

ショート #7 と同じ見た目を横型に移植したもの。`look="classic"`（既定）は #1 の古地図風のまま。

- **地図**：NASA Blue Marble の色 ＋ AWS Terrain Tiles の標高から作った陰影・海の深さ
  - 広域（60px/度・z7タイル）と地中海の詳細（160px/度・z8タイル）の2枚。足りない標高タイルは初回に自動で取得
  - 海岸沿いに衛星画像の海の色が混ざらないよう、陸の色を近くの陸地から補う
- **写真**：`Photo` 要素（ゆっくりズーム＆パン、左下にキャプション、右下にクレジット）
  - `mode="fit", side="l"/"r"` で胸像などを片側に寄せ、空いた側に解説カードを置ける
  - 素材は `engine/assets.py`（ショートと共通）が取得時にライセンスを確認：**パブリックドメイン / CC0 / CC BY のみ**
  - 使う写真の一覧は `episodes/photos_rome.py`。説明欄用のクレジット一覧は `*_timing.txt` の末尾に自動で出る
- **質感**：地図・写真の部分だけ色調補正・周辺減光・フィルムの粒子（字幕・カード・年表はくっきり）
- 図解の場面は暗い背景（`stage="plain"`）、年表など細かい図は紙の背景（`stage="paper"`）

## 画面構成（横型）

```
┌ ヘッダー（72px）：世界史ずかん｜第○章 章名｜シリーズ名・クレジット ┐
│                                                                   │
│  ステージ（816px）：地図カメラ・勢力範囲・矢印・図解                │
│                                                                   │
├ 字幕帯（124px）：1〜2行、【】は赤字                                ┤
└ 年表帯（68px）：現在の年＋ギリシア／ローマの2レーン               ┘
```

字幕と年表は専用の帯に置くので、地図や図解と重なりません。

## 生成方法

```bash
./setup.sh                                                    # 初回のみ（VOICEVOX・フォント・地図。ショートと共通）
python3 episodes/europe_long01_greece_rome.py                 # 動画・チャプター・台本・サムネイルを書き出し
python3 episodes/europe_long01_greece_rome.py --preview       # 各シーンの静止画だけ確認（output/preview/）
python3 episodes/europe_long01_greece_rome.py --preview --t=0,120.5   # 指定した秒の静止画
python3 episodes/europe_long01_greece_rome.py --thumb         # サムネイルだけ
python3 episodes/europe_long01_greece_rome.py --kana          # 読み上げのカナを確認（読み間違いチェック）
```

- 尺が上限（10分）を超えると、読み上げ速度を自動で上げます（今回は 1.15）。
- 書き出しは CPU のコア数だけ並列で行います（4コアで約30〜40分）。
- 音量は YouTube 基準の -14 LUFS に揃えます。BGM・効果音はプログラムで合成したもので、著作権の問題はありません。
- 初回は地図の下地（広域用・エーゲ海詳細用）を `.cache/` に作るので数分かかります。

## エンジン（`engine/`）

ショート用エンジンからの主な変更点：

- `core.py`
  - 1920×1080 のレイアウト（ヘッダー／ステージ／字幕帯／年表帯）
  - 地図の下地を2枚（広域 60px/度・エーゲ海詳細 240px/度）持ち、ズームに応じて自動で切り替え。範囲外は海で埋める
  - 陸地マスクを持つので、勢力範囲を「陸地だけ」塗れる
  - `Scene(chapter=("第1章", "エーゲ文明"))` で章を切り、YouTube チャプター用のタイムスタンプを自動出力
  - 年表帯は2レーン（ギリシア／ローマ）・区間ごとに目盛りの幅を変えられる・「前8世紀」などの表記も指定可
  - 長尺向けに BGM を16小節ごとに変化させる
  - 並列書き出し（区間ごとに書き出して最後に連結）
- `elements.py`
  - 地図：`Marker` `MapLabel` `Dot`（点の分布） `Glow` `Arrow` `Region`（勢力範囲・陸地だけ塗る）
  - 文字：`Card` `Stamp` `Caption` `TitleHook`（冒頭のつかみ） `ChapterBanner`（章見出し・自動）
  - 図解：`Labyrinth` `Polis` `PyramidTier` `Step` `Phalanx` `Ostracon` `Trireme` `Assembly` `AssemblyCross`
    `Temple` `Coins` `Table` `Summary`（総まとめ年表）
  - 演出のタイミングは秒か `"c1+0.5"`（そのシーンの2文目の開始から0.5秒後）で指定

- 終了画面（最後の約20秒＝総まとめ図）に、次に見てほしい動画・チャンネル登録を置く
