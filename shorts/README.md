# 世界史ずかん（YouTube ショート自動生成）

世界史の教科書内容を、**地図アニメ＋図解＋合成音声ナレーション**で解説する縦型ショート動画（1080×1920 / 30fps）を生成します。
地域ごとのシリーズで、1テーマにつき **受験版（高校生向け・30〜45秒）** と **教養版（一般向け・60秒以内）** の2本を作ります。

## 構成ルール（#1 のアナリティクスから）

#1 は約1,200〜1,300人のフィードに表示されたものの、**75〜78% が冒頭でスワイプ**し、表示が止まった。
視聴を始めた人の平均視聴時間は6割以上あったため、冒頭と終わり方を次のように変更した（#2 以降）。

1. **1コマ目からクイズを全部見せる**（0秒目の要素はフェードインしない。明るい背景に大きな「Q.」）
2. 受験版は **3択**、下部は「コメントで予想してね！」
3. 「40秒で総整理」などの前置きは入れず、2秒目から本題
4. **次回予告の画面は入れない**。最後は答え合わせで終わり、ループで冒頭の問いに戻る（次回は答えの画面に小さく表示）

## 生成方法

```bash
./setup.sh                                          # 初回のみ（VOICEVOX・フォント・地図）
python3 episodes/europe_01_aegean.py all            # 両方の版を書き出し
python3 episodes/europe_01_aegean.py exam --preview # 各シーンの静止画だけ確認
```

- 尺が上限（受験版45秒・教養版59秒）を超えると、読み上げ速度を自動で上げます。
- 音量は YouTube 基準の -14 LUFS に揃えます。
- BGM・効果音はプログラムで合成したもので、著作権の問題はありません。

## 構成

- `engine/core.py` … 音声合成、地図（Natural Earth）、字幕、年表バー、BGM、書き出し
- `engine/elements.py` … マーカー、矢印（民族移動）、解説カード、ハンコ、ポリス図解、比較表、次回予告
- `episodes/*.py` … 1話ごとの台本と演出（字幕の `【】` は赤字の強調、`/` は改行）
